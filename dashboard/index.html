Scaling under load

Failure drill: GPU server killed

The model server was deleted mid-traffic with no warning. Requests that had to stay private failed during the outage instead of being sent to the hosted API. That is the designed trade-off: an outage, not a data leak.

Evidence

Failure drill: hosted provider failing

For the whole run every third call to the hosted provider returned a rate limit, a server error or a 35 second timeout. The router sent each failed call to the GPU instead, and no user got an error. The cost showed up as waiting: calls that hit the timeout took about 30 seconds before switching over.
