How to read this

  • A hosted API charges for every request. Your own GPU costs the same whether it is busy or idle. Volume decides which is cheaper, and how busy you keep each GPU moves the crossover.
  • Quality comes before price. On document extraction the 7B model got fewer than half of the records right, so it is not an option there however cheap it looks.
  • These are one benchmark's prices: . Your models, prices and traffic will differ, so treat this as a way of thinking about the decision, not a quote.
